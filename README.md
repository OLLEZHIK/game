# BugBits 2.0 (Insect Warfare) 🐜⚔️

Тактическая RTS / Lane-Defense стратегия в макромире насекомых на движке **Godot 4.7**.

---

## 🌲 Особенности и Механики

1. **3 Боевые Полосы (3 Lanes)**:
   - **Северная линия (Top)**: извилистая тропа вдоль замшелых корней и гигантских грибов.
   - **Центральная линия (Mid)**: открытая просека, перекрытая **интерактивным поваленным бревном**. Бревно создает узкое горлышко (Chokepoint) и блокирует путь, пока его не распилят жуки-лесорубы (+35 редкой пыльцы за распил).
   - **Южная линия (Bottom)**: путь через поляну золотистых цветков нектара для сбора ресурсов.

2. **Классы Насекомых**:
   - **🐜 Муравей-Сборщик (Harvester)**: отправляется к цветам за нектаром (+25🍯 за рейс).
   - **🪓 Жук-Лесоруб (Woodcutter / Sapper)**: мощные челюсти для распила поваленных бревен и преград.
   - **🦏 Жук-Носорог (Armored Tank)**: 240 HP, прочный хитин и острый рог для продавливания линии.

3. **Камера**:
   - **Тактическая RTS-камера**: панорамирование (WASD / мышь), плавный зум, вращение (Q / E), быстрый переход к линиям (1, 2, 3).
   - **Режим «Bug-Cam»**: вид от лица выбранного жука (клавиша `F` или клик по жуку).

4. **Двухресурсная экономика**:
   - 🍯 **Нектар (Базовый)**: сбор рабочими с цветков, призыв пехоты и рабочих.
   - ✨ **Пыльца / Биомасса (Редкий)**: добыча с распила бревен и редких цветков.

---

## 🎮 Управление

- `W`, `A`, `S`, `D` / `Стрелки` — панорамирование камеры
- `Зажать ПКМ / Колесико мыши` — перетаскивание карты
- `Колесико мыши` — плавный зум (приближение / отдаление)
- `Q` / `E` — вращение угла обзора
- `1`, `2`, `3` — быстрый переход к Северной / Центральной / Южной линии
- `F` или клик по жуку — переключение в режим **Bug-Cam** (вид от лица жука)
- `Esc` — выход из режима Bug-Cam
- `Пробел` — ручной тест распила центрального бревна

---

## 🚀 Запуск игры

Требуется **Godot 4.7+**:
1. Откройте папку проекта в Godot Editor и нажмите **F5** (или **F6** на сцене `res://scenes/main.tscn`).
2. Либо запустите `run_game.bat` в Windows.
